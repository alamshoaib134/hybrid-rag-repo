## 📌 Module Overview

- **Chapter**: Search & Context Ingestion  
- **Core Concept**: Classic lexical search vs. Semantic search: inverted indices and term saturation  
- **Engineering Focus**: Constructs an inverted index and the complete BM25Okapi scoring algorithm from scratch in Python. Compares TF-IDF with BM25 term frequency saturation and document length normalization. Demonstrates why lexical matching is crucial for exact acronyms and IDs.

### 🔑 Key Search Topics & Concepts
`BM25 python from scratch` `BM25Okapi formula` `sparse retrieval vs dense` `inverted index python` `lexical search RAG` `AI From Scratch`

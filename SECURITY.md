# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |

## Reporting a Vulnerability

If you discover any security concerns, exposed keys, or vulnerabilities within this repository:

1. Please do **not** open a public issue.
2. Report the vulnerability privately to the project maintainers via [AI From Scratch](https://www.aifromscratch.in/).
3. Alternatively, contact the maintainer directly through the author profile at [https://shoaibalam.vercel.app/](https://shoaibalam.vercel.app/).

Thank you for helping keep the [AI From Scratch](https://www.aifromscratch.in/) community safe and secure!

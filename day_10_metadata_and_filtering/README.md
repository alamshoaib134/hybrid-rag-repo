## 📌 Module Overview

- **Chapter**: Search & Context Ingestion  
- **Core Concept**: Adding structured tags to chunks for deterministic, precise search  
- **Engineering Focus**: Explores metadata enrichment strategies. Implements pre-filtering vs. post-filtering benchmarks, simulates LLM Self-Querying to extract structured filter schemas from natural language queries, and handles multi-tenant access control.

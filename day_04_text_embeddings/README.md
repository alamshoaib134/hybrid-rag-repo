# Day 04: Text Embeddings (Concepts and Models)

**Chapter**: Foundations  
**Concept**: Translating human meaning into mathematical coordinates

---

## 📂 Contents & Structure

- [`day_04.ipynb`](./day_04.ipynb): Interactive Jupyter Notebook containing the full theoretical explanation, math derivations, architectural illustrations, and step-by-step runnable code cells.
- [`main.py`](./main.py): Standalone Python script consolidating the day's algorithms and test cases.

## 🚀 How to Run

### 1. Interactive Notebook (Recommended)
Launch Jupyter from the repository root:
```bash
jupyter notebook day_04_text_embeddings/day_04.ipynb
```

### 2. Standalone Script
Run directly from your terminal:
```bash
python day_04_text_embeddings/main.py
```

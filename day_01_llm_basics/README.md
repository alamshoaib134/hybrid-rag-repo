# Day 01: LLM Basics (Tokens, Context Window, Prompting)

**Chapter**: Foundations  
**Concept**: The engine under the hood: tokens, context windows, and prompts

---

## 📂 Contents & Structure

- [`day_01.ipynb`](./day_01.ipynb): Interactive Jupyter Notebook containing the full theoretical explanation, math derivations, architectural illustrations, and step-by-step runnable code cells.
- [`main.py`](./main.py): Standalone Python script consolidating the day's algorithms and test cases.

## 🚀 How to Run

### 1. Interactive Notebook (Recommended)
Launch Jupyter from the repository root:
```bash
jupyter notebook day_01_llm_basics/day_01.ipynb
```

### 2. Standalone Script
Run directly from your terminal:
```bash
python day_01_llm_basics/main.py
```

## 📌 Module Overview

- **Chapter**: Foundations & Demystification  
- **Core Concept**: Grounding fluent guesses with verifiable external truth  
- **Engineering Focus**: Diagnoses the mathematical and structural causes of LLM hallucinations. Demonstrates grounded generation, self-consistency verification, and building an automated LLM-as-a-Judge Faithfulness evaluator in Python.

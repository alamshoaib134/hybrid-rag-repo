## 📌 Module Overview

- **Chapter**: Search & Context Ingestion  
- **Core Concept**: Extracting clean text and tables from messy real-world files  
- **Engineering Focus**: Engineering robust document ingestion pipelines. Extracts clean structured text, tables, and metadata from complex PDFs using pdfplumber and pymupdf4llm, parses semantic HTML with BeautifulSoup, and formats Markdown for optimal LLM chunking.

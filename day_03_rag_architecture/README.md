# Day 03: RAG Architecture (Retriever, Generator, Pipeline Flow)

**Chapter**: Foundations  
**Concept**: The end-to-end blueprint: indexing, retrieval, and generation

## 📂 Contents & Structure

- [`day_03.ipynb`](./day_03.ipynb): Interactive Jupyter Notebook containing the full theoretical explanation, math derivations, architectural illustrations, and step-by-step runnable code cells.

## 🚀 How to Run

### 1. Interactive Notebook (Recommended)
Launch Jupyter from the repository root:
```bash
jupyter notebook day_03_rag_architecture/day_03.ipynb
```

### 2. Standalone Script
Run directly from your terminal:
```bash
python day_03_rag_architecture/main.py
```

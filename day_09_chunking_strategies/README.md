## 📌 Module Overview

- **Chapter**: Search & Context Ingestion  
- **Core Concept**: Breaking documents into optimal context units without losing meaning  
- **Engineering Focus**: Benchmarking chunking strategies for retrieval fidelity. Compares character-level fixed splitting, recursive text splitting, and semantic chunking based on consecutive embedding distance deltas. Evaluates chunk overlap ratios.
